## 공개 배포 전 필수 재검토 (미완료 · 2026-11-12 기록)
> 공개 데모 모드(`PRODUCTS_DEMO_MODE=true`)는 로그인 없이 누구나 상품을 보고 바꿀 수 있습니다.
> Vercel 공개 배포 전에 아래 항목을 다시 검토하고 결정합니다.
- ⬜ 요청 횟수 제한 도입 여부와 한도 결정 (`supabase/drafts/optional/003_demo_rate_limit.sql`, fail-closed)
- ⬜ 파일 업로드 악용 방지: 업로드 URL만 받고 상품은 저장하지 않는 반복 요청(고아 파일 누적), 800MB 소프트 한도의 한계, 고아 파일 정리 방법 ([specs/storage.md](./specs/storage.md)) — 5-A: 업로드 스위치(기본 꺼짐)와 미연결 20개 상한 구현. 자동 정리 없음, 사용자 구분 없음 → 배포 시 스위치를 켤지 결정
- 🔄 모든 Server Action(등록·수정·삭제·업로드 URL 발급)이 `getBusinessAccess()` 를 먼저 확인하는지 점검 — 등록·수정·삭제 3개 확인 완료(데모 모드 꺼짐이면 `FORBIDDEN`), 업로드 Action 2개도 데모 모드 → 업로드 스위치 순서로 확인(안전 검사 통과). 5-B 에서 추가되는 Action 은 다시 점검
- ⬜ Vercel 이미지 최적화·Supabase 저장/전송량 플랜 한도 확인
- ⬜ Vercel 에 `PRODUCTS_IMAGE_UPLOAD_ENABLED` 를 설정할지 결정 (설정하지 않으면 업로드 꺼짐, `NEXT_PUBLIC_` 금지)
- ⬜ 배포 빌드의 브라우저 번들에 secret 키·`sb_secret_`·키 이름이 없는지 재검사
- ⬜ Vercel 환경변수: `SUPABASE_SECRET_KEY`, `PRODUCTS_DEMO_MODE` 에 `NEXT_PUBLIC_` 이 붙지 않았는지 확인
- ⬜ 긴급 차단 절차 확인: `PRODUCTS_DEMO_MODE` 를 지우고 재배포하면 상품 화면이 차단되는지
